# Ремонт квартир «под ключ» — сайт

Точная (1:1) копия лендинга `https://xn----8sbhhcq4afdfepg6a.xn--p1ai/`
(«Ремонт квартир под ключ в Краснодаре — Регион Ремонта 23», платформа Tilda),
адаптированная для публикации на GitHub Pages.

**Опубликованная версия:** <https://voroninded1987-dot.github.io/23region-remonta/>

## Состав

- `index.html` — страница (вся разметка, инлайн-стили и скрипты Tilda);
- `assets/` — все картинки, шрифты Gilroy, CSS и JS, скачанные с CDN Tilda;
- `index-source.html` — исходный HTML сайта (не публикуется);
- `mirror.py` — скрипт, который заново собирает копию с живого сайта;
- `screenshot.py` — вспомогательный скрипт для сравнения с оригиналом.

## Локальный запуск

```bash
cd /Users/9ova/remont-clone
python3 -m http.server 8000
```

Затем откройте <http://127.0.0.1:8000/>

## Что воспроизведено

- полный дизайн и контент: шапка, первый экран, портфолио, этапы работ,
  преимущества, мастера, отзывы, FAQ, контакты, футер;
- попапы «Получить расчёт стоимости», «Вам перезвонить?» и «Политика
  конфиденциальности» (пошаговая форма-квиз работает);
- переключаемые вкладки этапов, аккордеон FAQ, галерея, анимации, адаптив
  (desktop и mobile проверены попиксельно против живого сайта);
- локальные изображения в исходном качестве (загрузка через
  `optim.tildacdn.com` отключена атрибутом `data-tilda-imgoptimoff="yes"`);
- шрифты Gilroy — локально.

## Доработки

- В шапке (под логотипом «Регион Ремонта») и в подвале размещён логотип
  **Exponent Digital** с подписью «разработка сайта и маркетинг» — клик
  ведёт на <https://voroninded1987-dot.github.io/exponent-digital/>.
- Canonical/OG-ссылки указывают на GitHub Pages-адрес сайта.

## Что убрано намеренно

- счётчик Яндекс.Метрики и счётчик статистики Tilda (трекинг);
- анти-flicker скрипт, который скрывает страницу до загрузки скриптов;
- скрипт Font Awesome Kit (отдаёт 403 при скачивании; страница не использует
  его иконки, CSS-версия Font Awesome оставлена).

Формы оставлены как в оригинале: при отправке они отправляют данные в форму
исходного проекта Tilda, поэтому заявки будут доходить владельцу сайта.
